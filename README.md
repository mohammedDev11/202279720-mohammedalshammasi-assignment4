# Personal Portfolio Web Application

## 📌 Overview

This project is a fully developed personal portfolio web application built as part of Assignment 4. It demonstrates my skills in frontend development, JavaScript functionality, API integration, and UI/UX design.

The website showcases my projects, integrates live GitHub data, and includes interactive features such as filtering, sorting, dark/light mode, and a project video modal.

---

## 🚀 Features

- 🌗 Dark / Light Mode (saved using localStorage)
- 👤 Visitor Name Personalization
- ⏱️ Time Spent on Website Counter
- 🎯 Project Filtering & Sorting System
- 🎥 Project Video Modal (click project → watch demo)
- 🔗 LinkedIn Project Links
- 🌐 GitHub API Integration (live repositories)
- 📩 Contact Form with Validation
- 📱 Fully Responsive Design

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (Custom Styling + Responsive Design)
- JavaScript (Vanilla JS)
- GitHub API
